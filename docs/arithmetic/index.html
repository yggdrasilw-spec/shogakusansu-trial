この試験版について

一般的な四則計算だけの練習ツールです。問題文・説明・画面は、この試験版用にAIの支援で新しく作成しました。教科書の文章・画像や、既存DBの教材を配信していません。

機械による全問題の数値検査と画面検査を行っています。教師による独立確認は未実施です。成績、理解度、苦手の原因や教育効果を判定する機能はありません。

記録はこのブラウザー内だけに保存します。氏名の入力、広告、解析サービス、外部への回答送信はありません。ブラウザーのデータを消すと記録も消えます。

公開ソースへの掲載は、第三者の権利や商用再利用を一括して許諾するものではありません。数学的な事実そのものに独占的な利用条件を設定しません。詳細は由来と利用条件をご覧ください。
