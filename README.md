# shogakusansuDB 計算試験版

[計算の小さな練習室を開く](https://yggdrasilw-spec.github.io/shogakusansu-trial/)

整数の四則計算だけを練習する、無料・広告なしの試験版です。たし算231問、ひき算231問、かけ算100問、あまりのないわり算90問、合計652問。答えと短い説明を表示し、現在の練習の記録をブラウザー内だけに保存します。外部への回答送信や解析サービスはありません。

これは全281項目の教材DBの正式公開版ではありません。問題文・説明・画面・コードはこの試験版用にAIの支援で新しく作成し、原資料、教科書の本文/画像、既存DBの教材、外部ライブラリやフォントを含めていません。

教師による独立確認は未実施です。理解度、苦手の原因や教育効果の判定を行いません。652問の全数値検査と、Edgeの画面・操作55チェックを実施しました。[検証記録](verification.json) と [ファイルの由来/hash](docs/manifest.json) を記録しています。

## 利用条件

一括の商用利用許諾・MIT/CC0等のライセンスは設定していません。すべての権利をユーザーが所有するとの申告や、AI生成部分に独占的な権利があるとの申告もしません。数学的事実に独占的な利用条件を設定しません。詳細は [NOTICE](docs/NOTICE.txt) を参照してください。

## 不具合の報告

画面の「不具合の報告メモを保存」からメモを保存し、困ったことを書き足して yggdrasil.w@gmail.com へ送れます。自動送信はしません。個人情報や回答履歴はメモに含めません。

## 再検査と配信

Node22以上で node scripts/verify.mjs を実行すると全数値と配信ファイルhashを再検査できます。GitHub Actionsでも同じ検査を実行します。GitHub Pagesはmainブランチのdocsだけを配信します。変更時は数値/画面検査とhash・検証記録を更新してから配信してください。

停止する場合はリポジトリSettings → Pagesの公開を停止します。利用者の端末内記録は遠隔削除しません。
